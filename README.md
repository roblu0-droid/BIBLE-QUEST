Project Description:
Bible Quest is an interactive quiz game for players who are into the Bible.
It features multiple questions with 60 sec to answer. The purpose of the 
game is only for educational goals for the historical events in the Bible.
I hope u enjoy the game!!

 Technologies Used
- Python
- Tkinter

Features
1. Multiple-choice questions (A, B, C, D).
2. 10 quiz questions.
3. 15-second countdown timer per question.
4. Randomized question order.
5. Automatic answer checking.
6. Score calculation.
7. Final results and answer review.
8. High score saving and loading.
9. Restart quiz functionality.
10. Progress indicator.

"Program Implementation"

Question Storage:
Questions, choices (A–D), and correct answers are stored in a Python list of dictionaries for easy access and checking.

Question Randomization:
The questions are shuffled randomly every time the game starts or restarts to make each game different.

Countdown Timer:
Each question has a 15-second timer. If time runs out, the question is automatically marked incorrect.

Answer Checking:
The program compares the player's selected answer with the correct answer to determine whether it is right or wrong.

Scoring System:
Players earn 1 point for every correct answer. The total score is displayed at the end of the quiz.

High Score System:
The highest score is saved in a text file and loaded whenever the game is opened again.

Functions Used:
The program uses functions to display questions, manage the timer, check answers, calculate scores, show results, save high scores, and restart the game.
